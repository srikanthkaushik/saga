          Compensations

          From order-service metrics, which it recalculates every 15 seconds, so these can trail the list below.

          Stuck sagas

          Sagas whose refund or release keeps being re-sent without a reply. Open one to retry or resolve it.

          Dead-letter topics

          Messages that failed after all retries. Replay sends them back to their topic; fix the cause first.

          Inject a message

          Publishes straight onto a saga topic, skipping the outbox. Use the presets to see dead-lettering and replay.
